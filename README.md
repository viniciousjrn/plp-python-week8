# Personal Mini-Toolkit (Week 8 Final Project)

## What This Toolkit Does
The Personal Mini-Toolkit is a menu-driven Python command-line application that brings together variables, conditionals, loops, lists, and user input. It lets users manage a live To-Do List, play a 1–20 Number Guessing Game, and run calculations in a Simple Calculator from one continuous menu.

## How to Run It
1. Make sure Python 3 is installed on your computer.
2. Open a terminal in the project folder and run:
   ```bash
   python toolkit.py
